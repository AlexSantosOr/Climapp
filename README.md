Aplicacion del Clima con API Externa



Aplicacion web desarrollada para consultar el clima actual de cualquier ciudad del mundo en tiempo real utilizando la

API de OpenWeatherMap.



Herramientas de IA Herramientas utilizadas: Gemini / Antigravity Uso de cada herramienta: Generacion de codigo: Se

utilizo la IA Gemini en parte para estructurar el diseno base en HTML con CSS y la logica en JavaScript para consumir

la API fetch . Depuracion y Manejo de Errores: Se le pidio a la IA Antigravity que ayudara a estructurar los bloques

try/catch y el manejo de codigos de estado HTTP (como el error 404 para ciudades inexistentes). Lo que hice sin

ayuda de IA: La planeacion y creacion inicial de la arquitectura de archivos, la eleccion de la API, las pruebas manuales

ejecutando la interfaz en el navegador y redaccion de este archivo README.md .
